# SQL Containers

A project for working with SQL databases in containerized environments.

## Description

This repository contains tools and configurations for managing SQL databases using containers.

## Features

- Database containerization
- SQL scripts and migrations
- Docker configurations
- Database management utilities

## Getting Started

```bash
# Clone the repository
git clone <repository-url>
cd sql-containers

# Build and run containers
docker-compose up -d
```
